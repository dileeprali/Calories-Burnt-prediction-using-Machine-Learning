# Calories-Burnt-prediction-using-Machine-Learning

Predict the number of calories burned based on user inputs like age, weight, duration, and heart rate — using a machine learning model with an interactive Gradio interface. Built entirely in Google Colab.

# Tech Stack
python
Google Colab
Pandas, NumPy
Scikit-learn (or TensorFlow if used)
Gradio (for UI)
Matplotlib / Seaborn (if used for data viz)

# ML Model Details
Model Type: Regression (e.g., Linear Regression, Random Forest)
Features Used: Age, Gender, Weight, Height, Duration, Heart Rate, Body Temperature
Target: Calories Burned
Datasets : Calories.csv,exercise.csv
